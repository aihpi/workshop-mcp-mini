# Workshop Description

## Titel
Welche Tools darf Ihr KI-Agent nutzen? MCP in der Praxis

## Zielgruppe
Unternehmen, die den Einsatz eigener KI-Agenten planen und lernen möchten, wie man geeignete Anwendungsfälle findet und diese über MCP sicher an Tools und Daten anbindet. Programmierkenntnisse sind nicht erforderlich.

## Abstract: 
Ein Agent ist nur so gut wie die Werkzeuge, auf die er zugreifen kann. Das Model Context Protocol (MCP) hat sich als offener Standard dafür etabliert: Statt für jedes System eine eigene Integration zu bauen, wird ein MCP-Server angebunden und der Agent kann ihn nutzen. Inzwischen gibt es Tausende solcher Server, von Datenbanken und Dokumentenspeichern bis zu Branchenanwendungen.

Der Workshop geht genau auf diese Ebene ein. Im Mittelpunkt steht die Frage, welche Arbeitsabläufe im eigenen Unternehmen sich sinnvoll agentisch abbilden lassen und welche MCP-Server dafür in Frage kommen. Die Teilnehmenden entwickeln dazu einen eigenen Entwurf.

Der zweite Schwerpunkt ist die Sicherheitsbewertung. Ein MCP-Server bekommt Zugriff auf Daten und darf im Namen des Nutzers handeln, was neue Angriffsflächen schafft. Wir gehen die wichtigsten Risiken durch und entwickeln ein einfaches Prüfraster für die Frage, welche Server im eigenen Kontext vertretbar sind und welche nicht.

Die Teilnehmenden gehen mit einem eigenen Workflow-Entwurf, einer Sicherheitseinschätzung dazu und konkreten nächsten Schritten aus dem Workshop.

## Tags
MCP, KI-Agenten, Tool-Integration, KI-Sicherheit, Prompt Injection

## Idee für Agenda

- 0-20 min: Introduction + Slides über MCP
- Short quiz to see if participants actually listened.
- 20-30 min: Zeigen eines detailierten Beispiels, wie man von Idee zu funktionierendem Agentic system kommt mit angebundenem MCP (vllt über Langflow) und um zu zeigen, welche Schritte man bei der Aufsetzung beachten muss, insbesondere bzgl Sicherheit. 
- 30 - 50 min: Teilnehmer arbeiten mit Papier und Stift einen MCP Usecase ab, ähnlich zu dem was in MCP_workflow_ideation beschrieben ist. Dafür durchsuchen sie gängige MCP server Listen und sollen insbesondere auf den Aspekt Sicherheit achten.
- 50 - 60 min: Teilnehmer stellen sich ihre Use-cases gegenseitig vor und diskutieren sie. 

Idealerweise sollten die ersten Punkte schneller gehen, sodass mehr Zeit für die Diskussion im letzten Teil bleibt.
