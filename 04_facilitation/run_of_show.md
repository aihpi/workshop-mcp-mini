# Run of Show — 60 minutes

**Before doors:** handouts on tables (worksheet + vetting checklist + server menu, one set per pair) · Langflow flow tested on venue Wi-Fi · fallback recording ready · presenter view open (speaker notes live in the slides).

| Time | Block | Cues |
|---|---|---|
| 0:00–0:15 | **Slides** (12) | Hard cap. If behind at slide 05 (ecosystem): compress 05 and 06 to one sentence each. Never cut 07–10 (security → checklist) — they're the workshop's promise. |
| 0:15–0:25 | **Live demo** | Per `03_demo/README.md`: flow runs (5 min), then checklist assessment out loud (5 min). If tech dies: recording; if that dies too, the checklist walkthrough alone carries the slot. |
| 0:25–0:45 | **Exercise** (pairs) | Briefing from slide 11 (90 sec), then circulate. Announce at 0:35: "you should be at the server search"; at 0:40: "start the checklist now". |
| 0:45–1:00 | **Pitches + discussion** | 2 min per pair: idea, server(s), verdict + one-line reasoning. 3–4 pairs, volunteers first. Close with synthesis (below). |

## Nudge questions while circulating

- Stuck on an idea: "Which recurring task means looking things up in 2–3 systems and producing a draft?" — or hand them the server menu and work backwards from an interesting server.
- Forgetting the injection surface: "Where does content from **outsiders** enter this workflow?"
- Anchor the worst case: "What is the most **irreversible** thing this agent could do?"

## Discussion prompts (0:45–1:00)

- "Did anyone land on 🔴? What made it non-defensible — the server, or the combination?"
- "Who found a first-party server from a vendor you already use?" (the check-before-you-build reflex)
- "Where would the human approval sit in your workflow?"

## Closing synthesis (2 min)

Three sentences to end on: (1) check the catalog before you build — your vendor may already ship a server; (2) the checklist's five questions are answerable from the listing page, so vetting is not an expert task; (3) the verdict you wrote plus the "next steps" box is your pilot plan — take it to your IT/works council conversation. Point at the repo/handout PDFs for take-home.

## Fallback decision points

| Failure | Response |
|---|---|
| Venue Wi-Fi dead | Exercise runs entirely on the printed server menu; demo runs from recording |
| Langflow dies mid-demo | Switch to recording; the checklist half of the demo needs no tech |
| Few participants (<6) | One group instead of pairs; facilitator scribes at a flipchart |
| Running over at 0:45 | Cut to 2 pitches, keep the synthesis — never end without it |
