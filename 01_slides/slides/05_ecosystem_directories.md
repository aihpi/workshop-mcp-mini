# Thousands of servers already exist

**Check before you build — someone probably built it:**

- **registry.modelcontextprotocol.io** — the official registry
- **github.com/mcp** · **pulsemcp.com** · **mcpservers.org** — large catalogs
- **mcpsafe.org** — catalog with safety scores
- Vendors increasingly ship an **official server**: GitHub, Atlassian, Stripe, Notion, Asana, ...

**First question for any use case: does my software vendor already offer one?**
